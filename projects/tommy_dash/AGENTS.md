# Tommy Dash working agreement

Before changing this project, read `README.md` and any applicable files under
`instructions/`.

- Keep metric definitions and data provenance explicit.
- Do not duplicate or change metrics governed by `../shared/`.
- Keep secrets, credentials, raw endpoint responses, and internal identifiers
  out of browser bundles and generated hosting packages.
- Separate deterministic data transformations from agent-authored narrative.
- Require citations or source references for agent-generated factual claims.
- Add validation for every new source adapter and material KPI calculation.

Until a framework is selected, avoid introducing package managers, build
systems, or deployment configuration merely as placeholders.
